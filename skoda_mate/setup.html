Škoda Mate setup

Two steps. Nothing is read from environment variables: your details are stored here, secrets encrypted.

1 · Dashboard login

Protects the dashboard. Pick any e-mail and password (8+ characters); they are separate from your Škoda account.

You are connecting from outside your home network, so Mate asks for its one-time setup code: only you can create the login. Find it in Mate's log (Docker: docker compose logs skoda-mate, DDEV: ddev logs) or in the file setup-code.txt in Mate's data folder. If you set SETUP_CODE, enter that.

2 · MyŠkoda API key

Mate uses Škoda's official public API, which signs in with a key instead of your password.

  1. Open the MyŠkoda app and create an API key for your car (go.skoda.eu/api-keys).
  2. Copy the key and your car's VIN (also in the app, under vehicle details).

Škoda limits each car to about 20 requests per hour and the key expires, so Mate reads your car every few minutes and tells you before the key runs out. The API is for personal use only. Official API documentation.
